# AWS Magic Monitor

Real-Time AWS Connect Operations Dashboard for RTAs.

## Features

- Real-Time AWS Connect Monitoring
- Occupancy Tracking
- Available Agents
- On Contact Agents
- Agent Flags
- Routing Profile Visibility
- CSV Export
- Draggable UI
- Resizable UI
- Live Refresh Timestamp
